Atualizar prestações de contas

Siga o fluxo em três etapas. O PDF é analisado no ChatGPT; aqui você importa apenas os arquivos JSON gerados pelo agente.

Rotina anual: gere dois relatórios separados no Portal das Parcerias — um de 2025 e outro de 2026. Não misture os anos na mesma importação.
1

Baixe os relatórios no Portal

Repita o procedimento uma vez para 2025 e outra para 2026.

  1. Acesse Portal das Parcerias → Área gestora → Relatórios → Prestações de Contas.
  2. Informe o ano 2025. Nos campos Área gestora, Modalidade do ajuste e Status da prestação de contas, mantenha TODAS.
  3. Clique em Visualizar. No relatório apresentado, clique em PDF e salve o arquivo.
  4. Repita os mesmos passos para o ano 2026 e salve esse relatório em outro arquivo.
Sugestão de nomes: prestacoes_2025.pdf e prestacoes_2026.pdf.
2

Peça ao agente para ler cada PDF

Abra o projeto do agente no ChatGPT, anexe um dos PDFs e peça a extração completa.

Abrir ChatGPT ↗Baixar instruções do agente
  1. Envie o PDF de 2025 ao agente e depois faça o mesmo com o PDF de 2026.
  2. Aguarde a leitura. O agente deve gerar um ou mais arquivos .json para baixar.
  3. Salve todos os JSON gerados de cada ano. Se o relatório for grande, podem existir várias partes.
Importante: o PDF deve ser anexado na conversa do ChatGPT. Nesta tela, envie somente os arquivos JSON gerados pelo agente.

Quando o projeto compartilhado estiver criado, configure o link direto para que este botão abra o agente diretamente.

3

Valide e importe os arquivos JSON

Selecione os arquivos gerados pelo agente. Você pode importar várias partes do mesmo ano juntas.
